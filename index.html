أبرز المشاريع والإنجازات التقنية

01

تحديث البنية التحتية في Eye Advertising

تنفيذ ترقية شاملة للبنية التحتية شملت نشر بيئة VMware ESXi، إضافة Additional Domain Controller (ADC)، وتكوين DHCP Failover و Secondary Reverse DNS.

VMware ESXi Active Directory DNS/DHCP
02

استراتيجية النسخ الاحتياطي (Disaster Recovery)

تطبيق حلول Veeam Backup & Replication و Hasleo Backup Suite، مع ربط المستودعات السحابية باستخدام Rclone لضمان حماية البيانات واستمرارية العمل.

Veeam Rclone Backup
03

إدارة الجدران النارية والشبكات (Firewalls)

تكوين وإدارة أجهزة Sophos XG/XGS و FortiGate، إعداد Site-to-Site VPN، SD-WAN، و IPsec لربط الفروع وتأمين شبكات المؤسسة.

Sophos XG FortiGate VPN
04

تقييم طاقة غرفة الخوادم (UPS Assessment)

إجراء تقييم دقيق لاحتياجات الطاقة لغرفة الخوادم وتقديم تقرير هندسي متكامل للإدارة لترقية وحدة عدم الانقطاع (10kVA UPS).

Infrastructure Power Management
05

أتمتة المهام والسكربتات (Automation)

تطوير سكربتات PowerShell و CMD لأتمتة مهام النسخ الاحتياطي اليومية، فحص السجلات، إدارة الصلاحيات، ومزامنة قواعد البيانات.

PowerShell Automation
06

إدارة أنظمة التخزين (Storage NAS)

إعداد وتهيئة TrueNAS (Core/SCALE) ومجلدات QNAP NAS، إعداد مشاركة الملفات عبر SMB، وتكوين اتصالات iSCSI و RAID Arrays.

TrueNAS QNAP iSCSI
